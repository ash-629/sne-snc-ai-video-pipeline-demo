# 工程边界与改进

## 已有能力

Python 模块化脚本、CLI 流程编排、外部 AI 服务调用、媒体处理、字幕算法、结构性质量检查、Google 平台集成和实际生产记录。部分编排仍由 AI 助手与人工协调执行。

## 当前限制

- **前后端与状态管理**：本包未实现 Web 前端、HTTP 服务、数据库、任务队列及多用户隔离。目前通过 CLI 和文件目录组织运行。
- **缓存有效性**：文件存在可能触发跳过，未绑定脚本及配置摘要；输入变更或部分文件残留会使结果过时。
- **时间对齐**：`align_words` 的一对一与部分修复分支依赖 token 数量；数量一致不保证语义一一匹配。比例回退是近似值，需检查复杂句。
- **质检语义**：漏读检查是启发式告警；默认模式可继续执行。拼音数量一致不证明多音字发音正确。缺少输入时部分检查会跳过，需要更强的任务门禁。
- **文档漂移**：`build_episode.py` 保留了一帧封面的旧说明，近期生产采用 0.5 秒停留 + 0.5 秒淡入。本包保留源码快照并在此说明，不把历史注释作为当前规范。
- **移植与部署**：生产环境依赖 FFmpeg、字体、角色素材、SDK、GPU 条件及目录约定；原依赖快照没有在干净环境完整验证。
- **在线操作**：Google OAuth 脚本包含历史授权经验注释，不应理解为平台通用或永久规则。在线 API 步骤没有在本次重新执行。

## 后续方向

最小工作台：创建节目、编辑角色与脚本、提交任务、查看阶段日志、重试失败步骤、预览和下载。后端保存项目/任务/产物记录，耗时任务交给独立 worker。随后增加输入摘要缓存、原子产物提交、超时/取消、明确的发布确认以及部署说明。

优先补充能够验证真实故障的测试：字幕正文保持、时间序列不倒退、漏读负例、拼音缺项、重试后不重复提交。测试范围优先覆盖可复现的故障与状态边界。
